# snowglobe-storyboard
--OUT OF SERVICE-- 
A interactive horror game
You're stranded in an elevator, with absolutely no idea how you ended up here. Every now and then, you hear shifting noises, and the whole place shakes. It's as if...you're not alone in here. And whatever it is, you don't think it'll be friendly
You feel weak, starved, and completely lost. But you know one thing. 
You need to get of here. ASAP.
